# Changelog

## 0.2.1 — 2026-10-12

- Extract the existing SDK into an independent, public-safe repository.
- Preserve the `luna_repro` import, `luna-repro` CLI and `luna.repro.page.v1` protocol; no result publication or execution behavior changes.
- Keep selected-source helpers and opt-in code snapshots from 0.2.0.
- Add independent tests, bilingual installation/manuals, clean notebooks, deterministic build scripts and explicit release allowlists.
- Preserve the original toy.py and walkthrough.py teaching source bytes.
- SDK releases and platform releases have separate version numbers. Platform authorization and storage policies remain authoritative.

0.2.0 was bundled with LUNA Research Platform. This independent release does not publish research data, run inference, or enable paid AI/GPU services.
